# API Reference

This section contains the API reference for the Hugging Face Evaluate Framework.

## Main Classes

- `ModelEvaluator`: Main class for running evaluations
- `MetricRegistry`: Manages evaluation metrics
- `DatasetLoader`: Handles dataset loading and preparation
- `EvaluationReport`: Container for evaluation results
- `Config`: Configuration management

## Modules

- `evaluate.evaluator`: Main evaluation logic
- `evaluate.metrics`: Metric management
- `evaluate.datasets`: Dataset utilities
- `evaluate.reports`: Result reporting
- `evaluate.config`: Configuration handling

For detailed API documentation, see the docstrings in the source code.
